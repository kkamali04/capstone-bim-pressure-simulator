          CSV format

          time_s,space_id,pressure_pa or time_s,positive_space_id,negative_space_id,pressure_pa. Use IFC room IDs and REFERENCE for the fixed 0 Pa reference.

          Fit reference leakage

          Use separate steady baseline CSV recordings with room-to-reference pressure, known flows, and the same sensor reference. Fits one common leakage multiplier.

          Chamber setup

          Start with the roughly 2 ft × 2 ft × 4 ft box discussed by the team. Confirm the actual internal dimensions. This creates a schematic shell; openings, partition, fan and tubing positions remain to be documented.

          Flow and leakage values below are modeling assumptions. The defaults are illustrative and need characterization. Changing dimensions changes the geometry and volume; this equilibrium solver does not infer fan dynamics from volume.

          Building a chamber replaces the current in-tab model. Download your reviewed project first if you need to keep it. Saved projects preserve this setup.
