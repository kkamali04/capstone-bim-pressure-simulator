Supported files and limits

IFC2x3 / IFC4 (.ifc) and PCI geometry JSON. Native RVT, DWG and IFCZIP need conversion. Maximum 2,000 objects, 600,000 triangles and 30 MB. Only geometry and properties actually represented in the file can be shown. Download research BIM samples.

Room membership uses IFC relationships or explicit manual review. Manufacturer ratings, installed measurements and unknown values remain distinct. Download your reviewed project to save edits; there is no server autosave.
